🛠 Tool-grounded answers

Every number flows through find_place → get_weather. If the tool returns nothing, the agent says NO DATA — it never estimates or interpolates.

🎙 Sarvam voice agent

Exotel telephony (—) connects to a Sarvam agent. Voice —, default language —. Hindi answer, English answer, other Indian languages supported.

🌧 Rain: probability + intensity

"70% baarish ki sambhavna hai" is never "baarish zaroor hogi." Forecast confidence is phrased honestly and fallbacks are never hidden.

⚠ Heavy rain & heat

Heavy-risk days get preparedness guidance with confidence stated — no exaggerated, invented disaster warnings.

🗣 Advisory-first arcs

Location first, one question at a time, short spoken answers: location → date → condition → temperature → rain → confidence → farming advisory.

📊 Data honesty

Only Open-Meteo model data is used and identified as such. A village name is not forecast data — coordinates are not a forecast.
